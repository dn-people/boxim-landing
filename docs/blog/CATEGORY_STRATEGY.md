# 동네방네 블로그 카테고리 운영 기준

## 카테고리 구조

글 URL은 기존처럼 `/blog/<slug>/`의 평면 구조를 유지한다. 카테고리는 글의 주제와 발행 순서를
관리하고 `/blog/?category=<category>`에서 목록을 거르는 데 사용한다. 카테고리별 글이 충분히 쌓이기
전에는 얇은 별도 카테고리 페이지를 만들지 않는다.

| ID | 표시명 | 포함하는 글 | 경계 |
|---|---|---|---|
| `it-tech` | IT·테크 | 기기 기능, 운영체제, 앱, 보안, 수리·관리 | 가격·계약 비교가 핵심이면 구매·요금 가이드 |
| `carrier-issues` | 통신사 이슈 | 통신사 공지, 청구·결제·개통 문제, 제도 변화와 대응 | 일반 요금제 선택법은 구매·요금 가이드 |
| `rental` | 렌탈 | 가전 렌탈의 계약, 월요금, 설치, 관리, 반환, 해지 | 계약 당사자와 상품별 조건을 공식 출처로 구분 |
| `product-reviews` | 제품 리뷰 | 특정 제품·모델의 사양, 차이, 사용 목적별 선택 | 실사용하지 않았다면 `사양 기반 리뷰`라고 명시 |
| `buying-guides` | 구매·요금 가이드 | 스마트폰·요금제·인터넷 구매, 비용, 약정, 비교 | 사건·공지 자체가 핵심이면 통신사 이슈 |

## 발행 균형

- 최근 10편에서 카테고리별 2편을 기준으로 부족한 카테고리를 우선한다.
- 같은 카테고리는 최대 2편까지만 연속 발행한다.
- `check:blog-gates`가 현재 분포, 부족분, 다음 우선 카테고리를 계산한다.
- 각 카테고리의 검증 가능한 후보를 `TOPICS.md`에 2개 이상 유지한다.
- 긴급한 통신사 장애·정책 변경처럼 시의성이 더 중요한 경우에는 우선순위를 바꿀 수 있다. 이때 PR에
  공식 발표 시각과 카테고리 순환을 건너뛴 이유를 남긴다.

## 2026년 9월 전환 기준

기존 33편의 분포는 구매·요금 가이드 14편, IT·테크 9편, 통신사 이슈 9편,
제품 리뷰 1편, 렌탈 0편이다. 최근 10편에도 렌탈과 제품 리뷰가 없으므로 다음 기본 순서는
`렌탈 → 제품 리뷰 → 렌탈 또는 제품 리뷰 중 부족한 쪽 → 통신사 이슈 → IT·테크`로 시작한다.
실제 다음 카테고리는 매 발행일의 원장 상태를 다시 계산해 정한다.

렌탈 콘텐츠는 동네방네가 통신판매중개자이고 계약 당사자는 렌탈 제휴사라는 점을 숨기지 않는다.
제품 리뷰는 제조사 공식 사양과 제품 페이지를 기준으로 작성하며, 확인하지 않은 체험·성능·만족도를
직접 사용한 사실처럼 쓰지 않는다.
