SKT 데이터 선물 전 번호·사용기한 확인 순서

2026년 11월 3일 · 구매·요금 가이드

요약 답변

데이터 선물은 보내는 사람의 잔여량과 받는 회선의 이용 조건을 함께 확인한 뒤 진행하세요. SKT T끼리 데이터 선물하기는 취소와 이월에 제한이 있으므로 수신 번호, 보낼 용량, 월말까지 쓸 양을 전송 전에 맞추는 것이 핵심입니다.

기준일: 2026년 11월 3일

가족이나 친구에게 남는 데이터를 보내려면 먼저 상대가 어느 번호로 사용할지 확인해야 합니다. 이 글은 2026년 11월 기준 SKT T끼리 데이터 선물하기 공개 안내에서 확인한 조건을 바탕으로 전송 직전의 점검 순서를 정리합니다. 다른 통신사의 나눔 서비스나 쿠폰 양도 조건을 그대로 적용하지 마세요.

선물 대상은 무엇부터 확인하나요?

데이터를 받을 사람의 실제 사용 번호와 가입 요금제를 먼저 확인하고, 보내는 회선에서도 해당 선물 기능을 이용할 수 있는지 살펴보세요.

공개 안내에는 SK텔레콤 고객 간 서비스로 설명되어 있고 LTE·3G 대상 요금상품이 제시되어 있습니다. 따라서 망 이름만 보고 알뜰폰까지 같은 조건이라고 판단하지 마세요. 5G나 개별 결합상품은 본인 상품의 최신 상세 안내와 선물 화면을 대조해야 합니다. 이 글은 전체 요금제의 대상 목록을 확정하는 안내가 아닙니다.

상대가 여러 번호를 쓰면 가족 연락용 번호와 실제 데이터를 쓰는 번호가 다를 수 있습니다. 먼저 “이번에 데이터를 사용할 번호가 무엇인지”를 물어보세요. 회선 확인과 보낼 양의 합의를 끝낸 뒤 입력하면 마지막 화면에서 판단할 항목이 줄어듭니다.

남은 데이터는 전부 보낼 수 있나요?

휴대폰에 보이는 전체 잔여량을 선물 가능량으로 생각하지 말고, 기본 제공 데이터와 선물 메뉴에 표시되는 가능량을 나누어 확인하세요.

일반 안내는 월 2회, 1회 100MB~1GB와 기본 제공량의 50% 이내, 전송 뒤 500MB 이상 잔여 조건을 설명합니다. 결합에 따른 예외가 있으므로 이 숫자를 모든 회선의 확정 한도로 사용하지 마세요. SKT 데이터·음성 리필 안내에서는 리필한 데이터도 선물 대상에서 제외합니다.

살펴볼 항목전송 전 확인할 내용기록할 값
받는 회선이번에 데이터를 사용할 번호인지 상대와 대조상대에게 확인한 번호
보내는 회선선물 메뉴의 가능량과 남은 횟수 확인보내기 전 화면 표시
본인 사용 계획남은 기간에 자신이 사용할 분량을 고려남겨 둘 양과 보낼 양
상대 사용 계획필요한 시점과 종료일까지 쓸 분량을 합의사용 목적과 필요량

가능한 양이 보여도 모두 보낼 필요는 없습니다. 출퇴근이나 외출 계획을 먼저 떠올리고, 본인에게 남길 양을 정한 뒤 선물량을 선택하세요. 표의 기록은 공식 한도를 대신하는 계산식이 아니라 두 사람이 조건을 맞추기 위한 메모입니다.

수신 번호는 어떻게 다시 맞추나요?

연락처에 저장된 이름만 믿고 전송하지 말고, 상대가 확인해 준 현재 번호와 입력한 번호를 마지막 확인 단계에서 다시 대조하세요.

이름이 같은 연락처, 예전 번호, 업무용 번호가 섞여 있다면 수신 대상을 먼저 정리하세요. “엄마에게 보낸다”는 기억보다 어느 번호를 입력했는지 확인하는 편이 구체적입니다. 번호를 대조할 때는 공개 게시판이나 단체 대화방에 전체 번호를 올릴 필요가 없습니다.

상대와 확인이 끝나지 않았다면 전송을 잠시 미루세요. 인증은 공식 앱이나 사이트에서 본인이 진행하고, 누군가에게 인증번호를 전달해 대신 보내 달라고 요청하지 마세요. 받는 사람을 정하는 과정과 본인 인증을 각각 끝낸 뒤 최종 확인 버튼을 누릅니다.

월말에는 사용기한을 어떻게 보나요?

월말에 선물할 때는 받은 날부터 한 달을 쓸 수 있다고 생각하지 말고, 이번 달 안에 상대가 사용할 분량과 날짜를 함께 확인하세요.

공식 안내상 선물 데이터는 받은 달 말일까지 쓰며 다음 달로 넘길 수 없습니다. 예를 들어 11월 말에 보내려면 12월 외출 계획에 쓸 데이터로 계산하지 마세요. “언제 필요하냐”를 먼저 물으면 지금 보내야 할지 다음 달에 다시 확인할지 판단하기 쉽습니다.

여행, 병원 대기, 통학처럼 사용할 상황도 함께 물어보세요. 필요한 양을 모르면 무조건 최대치를 보내기보다 평소 사용량과 남은 일정을 비교해 합의하세요. 전송 날짜와 사용 예정일을 메모하면 나중에 잔여량을 확인할 때도 혼동을 줄일 수 있습니다.

잘못 보낸 뒤 취소하거나 다시 나눌 수 있나요?

잘못 보낸 뒤 되돌리거나 받은 사람이 다시 나누는 방법을 기대하지 말고, 전송 전에 번호와 용량을 확정하는 절차를 마련하세요.

SKT 안내는 선물 완료 후 취소를 허용하지 않으며 받은 데이터를 재선물하거나 다른 회선과 공유할 수도 없다고 설명합니다. 수신자가 자기 휴대폰에서 쓸 것인지 먼저 확인하세요. 특히 태블릿이나 노트북에 필요한 데이터를 대신 보내려는 상황은 같은 서비스라고 가정하지 마세요.

전송 후 대상이 잘못됐다는 사실을 알았다면 확인한 시각과 내역을 남겨 공식 고객지원에 문의하세요. 문의를 접수했다는 이유만으로 복구가 확정되지는 않습니다. 같은 건을 반복 전송하기 전에 무엇이 완료됐는지부터 확인하는 것이 좋습니다.

전송 직전에는 어떤 순서로 확인하나요?

수신 회선과 번호를 먼저 정하고 가능량과 사용기한을 확인한 다음, 완료 내역과 상대의 수신 상태를 확인하는 순서로 진행하세요.

  1. 상대에게 데이터를 사용할 현재 번호와 필요한 시점을 물어봅니다.
  2. 양쪽 요금제의 대상 여부와 본인 회선의 선물 가능량을 확인합니다.
  3. 본인이 남길 분량과 상대가 이번 달 사용할 분량을 맞춥니다.
  4. 입력한 수신 번호와 용량을 읽고 공식 경로에서 본인 인증을 진행합니다.
  5. 완료 화면을 확인하고 상대에게 자기 회선의 수신 내역을 확인해 달라고 요청합니다.

보내기 버튼을 눌렀는지 기억이 불분명할 때는 새로 보내기부터 하지 마세요. 먼저 완료 내역을 살펴보고 상대와 대조합니다. 문의가 필요하면 날짜, 시각, 보낸 용량, 화면에 표시된 상태를 정리하고 개인정보가 포함된 화면은 공개하지 마세요.

다음 달 요금제도 함께 바꿔야 하나요?

이번 달의 일시적인 부족분을 해결하는 일과 다음 달 요금제를 고르는 일을 나누고, 반복되는 사용량을 확인한 뒤 변경을 검토하세요.

한 번 선물받았다는 이유만으로 요금제를 바꿀 필요는 없습니다. 외출이 많았던 달인지, 평소에도 계속 모자라는지부터 살펴보세요. 반복된다면 데이터 사용량별 요금제 선택 기준으로 최근 사용량과 비용을 다시 비교할 수 있습니다. 동네방네에서도 요금제를 비교할 때 가족 간 지원에 항상 의존하는 구성인지 함께 살펴보시길 권합니다.

노트북 연결이 목적이면 테더링·공유 데이터 확인 기준을 따로 확인하세요. 상대 휴대폰의 데이터 부족과 다른 기기의 통신 연결은 필요한 조건이 다릅니다. 더 많은 확인 항목은 블로그 목록에서 살펴볼 수 있습니다.

자주 묻는 질문

가족 이름으로 저장된 연락처면 바로 보내도 되나요?

상대에게 이번에 데이터를 사용할 현재 번호를 먼저 확인하세요. 예전 번호나 업무용 번호가 섞여 있다면 입력한 수신 번호를 다시 대조하는 것이 좋습니다.

리필해서 늘어난 데이터도 선물할 수 있나요?

SKT 리필 안내는 리필한 데이터를 T끼리 데이터 선물하기로 보낼 수 없다고 설명합니다. 전체 잔여량과 선물 가능한 양을 구분해 확인하세요.

월말에 받은 데이터는 다음 달까지 쓸 수 있나요?

T끼리 데이터 선물하기 안내상 받은 데이터는 해당 월말까지 사용하며 이월되지 않습니다. 상대가 실제로 사용할 날짜를 먼저 확인하세요.

번호를 잘못 입력했으면 선물을 취소할 수 있나요?

T끼리 데이터 선물하기 안내는 선물 완료 뒤 취소가 불가능하다고 설명합니다. 완료 내역을 정리해 공식 고객지원에 문의하되 복구를 전제로 추가 전송하지 마세요.

받는 사람과 연락이 안 되면 어떻게 하나요?

전송을 서두르기보다 수신 번호와 필요한 양을 확인할 수 있을 때까지 기다리세요. 이미 보냈다면 완료 내역을 먼저 확인하고 상대와 수신 상태를 대조하세요.
