해외 로밍 하루 요금 계산법, 현지 자정과 24시간

2026년 11월 25일 · 구매·요금 가이드

요약 답변

해외 로밍의 하루는 상품에 따라 현지 수도의 자정으로 나누거나 시작 시각부터 24시간으로 계산합니다. 밤늦게 도착한다면 시간 기준부터 확인하고, 데이터를 사용한 날만 청구되는지 신청 기간 전체가 청구되는지도 따로 보세요.

기준일: 2026년 11월 25일

로밍의 ‘하루’는 언제부터 언제까지인가요?

로밍의 하루는 상품에 따라 방문국 수도의 자정으로 나뉘거나 정해진 시작 시각부터 24시간으로 계산됩니다. 2026년 11월 기준으로 SK텔레콤의 OnePass Data VIP 기본형과 기간형만 비교해도 두 방식이 모두 있습니다. 상품명에 ‘하루’라고 쓰여 있으면 상세 페이지에서 어느 지역의 시계인지, 시작점이 언제인지부터 확인하세요.

일정표에는 항공기 착륙 시간 외에 공항에서 지도를 열거나 차량을 부르는 시각까지 적어 두세요. 같은 저녁에 도착해도 바로 데이터를 쓰는 일정과 숙소에 간 뒤 다음 날부터 쓰는 일정은 필요한 이용 시간이 달라질 수 있습니다. 그 다음에 이용일을 세는 방법과 실제 청구 조건을 각각 대조합니다.

밤 11시 50분과 다음 날 0시 10분에 쓰면 어떻게 되나요?

현지 수도 자정을 기준으로 두 시각에 각각 데이터를 쓰면 사용 시간이 짧아도 요금 계산에서 이틀로 나뉩니다. 예를 들어 SK텔레콤 OnePass Data VIP 기본형으로 도쿄에 도착해 밤 11시 50분에 로밍 데이터로 지도를 열고, 자정이 지난 0시 10분에 다시 데이터를 썼다고 가정해 보세요. 두 건은 각각 다른 날짜에 속하므로 하루 요금이 두 번 적용됩니다.

반대로 자정이 지나서만 로밍 데이터를 썼다면, 기본형의 데이터 하루 요금은 사용한 날짜에만 적용됩니다. 지도를 닫은 뒤에도 자동 동기화나 앱 알림으로 데이터가 사용될 수 있으니, 실제 청구를 볼 때는 두 날짜에 데이터 이용 기록이 있는지 확인하세요.

24시간형은 현지 도착 시간을 그대로 입력하나요?

신청 화면이 한국 시각을 받는 상품이라면, 현지에서 데이터를 처음 쓸 시각을 한국 날짜와 시각으로 바꿔 입력하세요. 예를 들어 타이베이에서 12월 4일 밤 11시 30분에 사용을 시작하려면 한국 시각으로는 12월 5일 0시 30분입니다. SK텔레콤 OnePass Data VIP 기간형으로 24시간만 신청한다면 현지에서는 다음 날 밤 11시 30분에 그 구간이 끝나는 일정입니다.

귀국편이 다음 날 오후가 아닌 다음 날 밤이라면, 공항에 도착하는 시각보다 탑승 직전까지 데이터가 필요한지부터 확인하세요. 항공권의 출발 시각과 도착 시각은 서로 다른 시간대로 표시될 수 있습니다. 휴대폰 세계 시계로 두 도시의 날짜를 나란히 확인하고, 항공편이 바뀌면 신청 내역의 종료 시각도 함께 확인하세요.

24시간을 기준으로 하는 상품은 청구 방식도 같나요?

24시간으로 나누는 상품끼리도 데이터를 한 번 쓰면 신청 기간 전체를 청구하는 상품과 사용한 날을 따지는 상품이 있습니다. 예를 들어 세 구간을 신청해 첫째 날과 셋째 날에만 데이터를 사용했다면, SK텔레콤 OnePass Data VIP 기간형은 신청한 세 구간의 이용요금이 청구됩니다. KT 하루종일 로밍 베이직 기간형은 데이터 이용이 없는 날의 요금이 빠진다고 안내합니다.

2026년 11월 확인 상품하루를 나누는 기준데이터 로밍 요금이 붙는 조건
SKT OnePass Data VIP 기본형방문국 수도의 0시부터 다음 자정까지로밍 데이터를 사용한 날짜에 하루 요금
SKT OnePass Data VIP 기간형한국 시각으로 지정한 시작부터 24시간 단위로밍 데이터를 한 번 이상 쓰면 신청 기간 전체 요금
KT 하루종일 로밍 베이직 기간형신청한 시각부터 24시간 단위데이터를 한 번도 사용하지 않은 날은 미청구
LG U+ 하루 데이터 로밍(기간형)설정한 시작 시각부터 24시간 단위해당 구간에 데이터를 이용하면 요금 발생

같은 상품군에도 다른 기준이 있습니다. KT 하루종일 로밍 베이직 자동형은 최초 가입 때 지정한 시작 시각이 기준입니다. 이후 출국에서는 해외에서 휴대폰을 켠 시각부터 24시간 단위로 계산한다고 안내합니다. 상품군 이름을 메모할 때 기본형·자동형·기간형까지 적어 두면 가입 전후로 같은 상품을 비교하기 쉽습니다.

종료 시각과 음성·문자 요금은 왜 따로 보나요?

데이터 이용이 끝나는 시각과 일반 전화·문자에 요금이 붙는 조건은 상품별로 따로 확인해야 여행 비용을 계산할 수 있습니다. LG U+ 하루 데이터 로밍 기간형은 설정 기간을 지나면 데이터 로밍이 자동 차단되고, 음성통화와 문자는 별도의 과금 조건이 적용된다고 안내합니다. SK텔레콤 OnePass Data VIP 기간형은 이용 기간이 끝나면 자동 해지되며 데이터 로밍 차단 서비스가 가입된다고 안내합니다.

반면 SK텔레콤 OnePass Data VIP 기본형은 해지하지 않으면 다음 출국에도 대상 국가에서 로밍 이용 시 적용됩니다. 이번 여행을 마치고 다음 여행에는 다른 상품을 쓸 예정이라면 기본형이 남아 있는지 확인하세요. 로밍 이용 시각과 별개로 분실 상황에 대비하려면 해외 로밍 전 휴대폰·유심 분실 대비 순서도 참고하세요.

신청 직전 어떤 순서로 확인하면 되나요?

데이터가 필요한 첫 시각과 마지막 시각을 적은 뒤, 신청 화면의 시간대와 청구 규칙을 차례로 대조하세요.

  1. 구간을 적습니다. 착륙과 출국만 보지 말고 공항 이동, 심야 도착, 환승 중 지도나 연락이 필요한 시간을 기록하세요.
  2. 지원 지역을 확인합니다. 여행지와 환승국에서 적용되는지, 지정된 현지 통신망이 있는지 상품 상세에서 확인하세요.
  3. 시계를 맞춥니다. 방문국 수도와 여행지의 시각이 다르면 둘을 구분하세요. 서머타임이나 여러 국가를 오가는 날의 예외는 공식 안내에서 확인하세요.
  4. 청구될 날을 셉니다. 데이터를 사용한 날짜만 계산하는지, 한 번 사용하면 예약한 기간 전체 요금이 붙는지 확인하고 일 요금과 곱해 비교하세요.
  5. 신청 내역을 저장합니다. 상품명, 기준 시간대, 시작·종료 일시를 캡처하세요. 일반 통화와 문자, 기간 종료 뒤의 데이터 차단 여부도 함께 확인하세요.

자주 묻는 질문

밤 11시 50분에 켜면 다음 날 밤까지 하루인가요?

현지 수도 자정을 기준으로 하는 상품에서 밤 11시 50분과 다음 날 0시 10분에 데이터를 쓰면 이용일은 이틀입니다. 시작 시각부터 24시간을 계산하는 상품이라면 두 시각이 같은 24시간 안에 있는지 확인하세요.

SKT 기간형에 입력하는 시각은 어느 나라 시간인가요?

OnePass Data VIP 기간형은 한국 시각으로 시작 일시를 지정합니다. 해외에서 처음 데이터가 필요한 시각을 한국 날짜와 시각으로 바꾼 뒤 신청 내역에 표시된 종료 시각까지 확인하세요.

기간형은 중간에 안 쓴 날의 요금이 빠지나요?

SKT OnePass Data VIP 기간형은 데이터 로밍을 한 번 이상 이용하면 신청 기간 전체의 이용요금이 청구됩니다. KT 하루종일 로밍 베이직 기간형은 데이터를 한 번도 쓰지 않은 날에는 요금이 청구되지 않는다고 안내합니다.

목적지와 수도의 시계가 다르면 무엇을 봐야 하나요?

현지 수도 시각을 기준으로 안내하는 상품은 여행 도시와 수도의 시차를 확인하세요. 서머타임 처리 방식과 여러 국가에서 같은 날 이용할 때의 기준은 상품 상세의 안내를 따르세요.

데이터 로밍이 끝나면 음성통화와 문자도 모두 차단되나요?

데이터 로밍이 종료될 때의 조치와 일반 음성통화·문자의 이용 조건은 별개로 확인해야 합니다. LG U+ 하루 데이터 로밍 기간형은 설정 기간 뒤 데이터가 차단되며, 음성통화와 문자는 별도의 과금 조건이 적용된다고 안내합니다.
