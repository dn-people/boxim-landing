갤럭시 Z 폴드8·폴드8 울트라 사양 기반 비교

2026년 10월 2일 · 제품 리뷰

요약 답변

접었을 때 폭이 좁은 형태와 3배 광학 줌이 필요하면 폴드8 울트라, 14g 가볍고 세로가 짧은 형태가 편하면 폴드8이 맞습니다. 메모리·저장공간과 보안 업데이트 기한은 같아서 크기와 카메라를 먼저 비교하세요.

기준일: 2026년 10월 2일

이 글의 범위

직접 사용한 후기가 아니라 삼성전자 대한민국 공식 스펙 페이지를 바탕으로 정리한 사양 기반 리뷰입니다. 가격과 구매 혜택은 시점과 판매처에 따라 달라져 비교에서 뺐습니다.

폴드8과 폴드8 울트라는 무엇이 다른가요?

두 모델은 접었을 때 모양과 화면 크기, 후면 카메라 구성에서 갈리고 메모리와 저장공간은 같습니다.

갤럭시 Z 폴드8 공식 스펙과 갤럭시 Z 폴드8 울트라 공식 스펙을 나란히 놓고 보면, 울트라는 폴드8을 그대로 키운 제품이 아닙니다. 폴드8은 접었을 때 세로가 짧고 폭이 넓습니다. 울트라는 세로로 길고 폭이 좁아 일반 바형 스마트폰에 가까운 모양입니다.

화면 크기는 모서리를 직각으로 보고 대각선으로 잰 값이라 실제로 보이는 영역은 더 작습니다. 배터리 용량은 IEC 61960 표준에 따른 표준 용량이고, 동영상 재생 시간은 삼성의 시험 조건에서 나온 수치입니다.

접었을 때 크기와 무게는 얼마나 차이 나나요?

울트라는 14g 무겁지만 접은 폭이 9.1mm 좁고 두께도 0.8mm 얇아 무게만으로 휴대성을 정하기 어렵습니다.

폴드8은 접으면 세로 123.9mm, 폭 81.9mm, 두께 9.7mm입니다. 울트라는 세로 158.4mm, 폭 72.8mm, 두께 8.9mm입니다. 세로는 울트라가 34.5mm 깁니다. 폭 72.8mm는 갤럭시 S26(71.7mm)과 S26+(75.8mm) 사이에 들어가는 수치라, 접은 울트라는 조금 두꺼운 바형 스마트폰을 쥐는 것과 비슷한 폭입니다.

폴드8은 세로가 짧아 얕은 주머니나 작은 가방에 넣기 쉽지만 폭이 81.9mm라 한 손으로 감싸 쥐기에는 넓을 수 있습니다. 손 크기는 사양표에 없으니 매장에서 두 모델을 접은 채로 쥐어 보세요. 평소 쓰는 것과 비슷한 케이스를 씌운 전시품이면 더 좋습니다. 엄지가 화면 반대편 끝까지 닿는지도 같이 보세요.

펼친 화면과 커버 화면은 어떻게 다른가요?

울트라는 메인 화면이 9.9mm, 커버 화면이 26.4mm 더 크고 펼쳤을 때의 가로세로 비율도 다릅니다.

폴드8의 메인 화면은 193.2mm이고, 펼친 본체는 세로 123.9mm에 가로 161.4mm로 가로가 더 깁니다. 울트라의 메인 화면은 203.1mm이며 펼친 본체는 세로 158.4mm, 가로 143.2mm로 세로가 조금 더 깁니다. 두 모델 모두 Dynamic AMOLED 2X에 최대 120Hz 주사율을 지원합니다.

커버 화면 차이가 더 큽니다. 폴드8은 138.4mm(1972×1248), 울트라는 164.8mm(2520×1080)입니다. 접은 채로 메신저 답장, 검색, 결제를 처리하는 시간이 길다면 커버 화면이 길고 큰 울트라 쪽을 먼저 볼 만합니다. 짧은 확인만 접은 채로 하고 나머지는 펼쳐서 쓴다면 폴드8의 커버 화면으로도 부족하지 않을 수 있습니다. 매장에서는 자주 쓰는 앱 두 개를 펼친 화면에 나란히 띄워 글자 크기와 여백을 비교해 보세요.

카메라는 울트라가 얼마나 더 갖췄나요?

울트라는 200MP를 포함한 후면 카메라 3개와 3배 광학 줌을 갖췄고, 폴드8은 50MP 카메라 2개 구성입니다.

공식 표기는 울트라가 200MP(F1.7)·50MP(F1.9)·10MP(F2.4)에 3배 광학 줌과 최대 30배 디지털 줌입니다. 폴드8은 50MP(F1.8)·50MP(F1.9)에 광학 줌 수준의 2배 줌, 최대 10배 디지털 줌입니다. 전면과 커버 카메라는 두 모델 모두 10MP이고, 동영상은 둘 다 8K 30fps까지 촬영할 수 있습니다.

화소 수와 줌 배율이 사진의 만족도를 정해 주지는 않습니다. 그래도 공연장이나 운동장처럼 멀리 있는 대상을 자주 찍는다면 3배 광학 줌이 있는지는 따져 볼 항목입니다. 가까운 인물과 음식, 문서 촬영이 대부분이라면 폴드8의 구성으로도 충분할 수 있습니다. 지금 휴대폰 사진첩에서 줌으로 찍은 사진이 얼마나 되는지 세어 보면 판단하기 쉽습니다.

배터리와 저장공간, 지원 기간도 다른가요?

배터리는 울트라가 200mAh 크고, 저장공간 구성과 보안 업데이트 지원 기한은 두 모델이 같습니다.

표준 용량은 폴드8 4,800mAh, 울트라 5,000mAh입니다. 공식 동영상 재생 표기는 각각 최대 26시간과 27시간으로 1시간 차이입니다. 울트라는 화면도 더 크기 때문에 용량 차이를 그대로 사용 시간 차이로 읽으면 안 됩니다. 펼친 화면을 얼마나 오래 켜 두는지가 실제 사용 시간을 더 크게 좌우합니다.

저장공간은 두 모델 모두 256GB·512GB·1TB이고 메모리는 256GB와 512GB가 12GB, 1TB가 16GB입니다. 실제 사용 가능 용량 표기도 225.9GB, 480.9GB, 991.4GB로 같습니다. UWB와 삼성 DeX는 둘 다 지원합니다. 2026년 10월 기준 보안 업데이트 지원 기한은 두 모델 모두 2033년 7월 31일이며, 이 날짜는 바뀔 수 있으니 구매할 때 공식 페이지에서 다시 확인하세요. S펜 지원 여부는 두 모델의 스펙 표에 적혀 있지 않아 이 글에서는 다루지 않았습니다.

어떤 사람에게 어느 모델이 맞나요?

접은 상태로 오래 쓰고 줌 촬영이 잦으면 울트라, 가볍고 세로가 짧은 폴더블을 원하면 폴드8을 먼저 보세요.

울트라는 접었을 때 바형 스마트폰처럼 쓰다가 필요할 때 펼치는 사람에게 맞는 사양입니다. 커버 화면이 크고 광학 줌이 있지만 215g의 무게와 158.4mm의 세로 길이를 감수해야 합니다. 폴드8은 201g으로 더 가볍고 접으면 세로가 짧습니다. 접은 폭이 넓은 점은 호불호가 갈릴 수 있습니다.

가격은 이 비교에 넣지 않았습니다. 같은 저장용량으로 맞춘 뒤 자급제 가격과 통신사 약정 조건을 따로 계산해야 정확합니다. 계산 방법은 자급제폰과 통신사 약정의 2년 총비용 계산법에 정리해 두었고, 동네방네에서는 자급제폰과 알뜰폰 요금제 조건을 함께 볼 수 있습니다.

구매 전에는 어떤 순서로 확인하나요?

접은 모양을 먼저 고르고, 커버 화면 사용 시간과 줌 촬영 빈도, 저장용량 순서로 정한 뒤 가격을 비교하세요.

  1. 지금 쓰는 휴대폰의 폭과 무게를 확인하고, 접은 폭 72.8mm와 81.9mm 중 어느 쪽이 손에 맞는지 매장에서 쥐어 봅니다.
  2. 바지 주머니와 자주 드는 가방에 세로 158.4mm가 들어가는지 확인합니다.
  3. 하루 중 접은 채로 쓰는 시간과 펼쳐서 쓰는 시간을 대략 나눠 적습니다.
  4. 최근 사진첩에서 줌으로 찍은 사진이 얼마나 되는지 세어 3배 광학 줌이 필요한지 판단합니다.
  5. 현재 저장공간 사용량을 보고 256GB·512GB·1TB 중 하나를 정합니다.
  6. 모델과 용량을 정한 다음 판매처별 최종 가격과 보증·반품 조건을 비교합니다.

바형 울트라까지 후보에 있다면 갤럭시 S26 울트라·Z 폴드8 비교를, 플립까지 함께 고민한다면 갤럭시 폴더블8 시리즈 선택 가이드를 이어서 보세요. 다른 구매 기준은 동네방네 블로그에 있습니다.

자주 묻는 질문

갤럭시 Z 폴드8과 폴드8 울트라의 가장 큰 차이는 무엇인가요?

공식 사양상 접었을 때의 크기와 화면 크기, 후면 카메라 구성이 다릅니다. 메모리와 저장공간 선택지, 보안 업데이트 지원 기한은 두 모델이 같습니다.

폴드8 울트라가 폴드8보다 무겁나요?

삼성 공식 사양은 폴드8 울트라 215g, 폴드8 201g으로 울트라가 14g 무겁습니다. 다만 울트라는 접었을 때 폭이 72.8mm로 더 좁고 두께도 8.9mm로 얇아서 무게와 그립은 따로 확인해야 합니다.

두 모델 모두 광학 줌을 지원하나요?

폴드8 울트라는 200MP·50MP·10MP 후면 카메라와 3배 광학 줌, 최대 30배 디지털 줌으로 표기돼 있습니다. 폴드8은 50MP 카메라 2개와 광학 줌 수준의 2배 줌, 최대 10배 디지털 줌으로 안내됩니다.

배터리는 폴드8 울트라가 훨씬 오래가나요?

표준 용량은 폴드8 울트라 5,000mAh, 폴드8 4,800mAh입니다. 공식 동영상 재생 표기는 각각 최대 27시간과 26시간이라 차이가 1시간이며, 실제 사용 시간은 화면 사용 방식에 따라 달라집니다.

저장공간과 보안 업데이트 기한은 같은가요?

두 모델 모두 256GB·512GB는 메모리 12GB, 1TB는 16GB로 안내됩니다. 2026년 10월 기준 공식 스펙의 보안 업데이트 지원 기한도 2033년 7월 31일로 같습니다.
